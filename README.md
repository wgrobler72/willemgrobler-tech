# willemgrobler.tech

Professional career portfolio for Willem Grobler.

## Run locally

1. Install Node.js LTS.
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Production build

Run:

```bash
npm run build
```

Because `output: "export"` is enabled, the finished static website is generated in the `out/` folder.

## Recommended hosting

Deploy to Vercel, Cloudflare Pages, Netlify, or another static hosting provider.

The domain `willemgrobler.tech` can remain registered with GoDaddy. Point its DNS records to the hosting provider after deployment.

## Before publishing

- Add a professional email address once configured.
- Add a downloadable general resume to `/public/`.
- Add screenshots to selected projects only if they contain no confidential information.
- Do not publish internal IP addresses, network diagrams, credentials, server names, customer data, or sensitive employer information.
